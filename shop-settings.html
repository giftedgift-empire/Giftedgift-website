You can create several weight bands for the same carrier.

Example:
Chronopost France
0–1 kg → one delivery price
1–2 kg → another delivery price
2–5 kg → another delivery price

Use two-letter country codes such as FR, DE, BE.
Important: Create one shipping rate for each weight band. The customer's cart weight will later be used automatically to select the correct delivery charge at checkout.

Leave Maximum Weight empty only if this should be the final weight band with no upper limit.
